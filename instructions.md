# Installation
Follow the instructions from Cebinae to set up the base environment. Additional configurations for the network topology were made in dumbbell_long.cc. Tax mechanisms were implemented in tcp-congestion-ops.cc.
# Running Experiments
Code for this project is run from the experiment.sh file. By default, running this file will move all files for each iteration of the experiment from the Linux partition to a desired location. This file will run the Cebinae experiment for a given tax rate (updates to tax rates should be made in tcp-congestion-ops.cc (FIFO queuing) and fig1.json (Cebinae queuing). 
# Analyzing Results
Results (throughput, fairness, queuing, etc.) are analyzed in Jupyter Notebooks (each notebook corresponds to one taxation mechanism). Throughput and fairness results for each tax rate are computed from the edited .pcap files and plotted in Jupyter Notebooks as individual cells; data is summarized in the last three plots. 
Junix is a package that should be used to save all plots generated by the Jupyter Notebook (credit: https://medium.com/@damienmarlier). Instructions and source: https://medium.com/analytics-vidhya/export-images-from-jupyter-notebook-with-a-single-command-422db2b66e92
